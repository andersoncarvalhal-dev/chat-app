# 💬 Chat em Tempo Real (WebSocket)

Um projeto de chat bidirecional cliente-servidor orientado a eventos, desenvolvido com **Node.js** e **Socket.IO**. A aplicação simula a experiência de comunicadores modernos, contando com uma interface responsiva, tela de entrada e identificação de usuários.

**🟢 Projeto Online:** Teste a aplicação em funcionamento acessando [https://chat.pimencon.com.br/](https://chat.pimencon.com.br/).

---

## ✨ Funcionalidades
- Comunicação bidirecional em tempo real (sem recarregar a página).
- Tela inicial modal para identificação do usuário.
- Design responsivo adaptado para computadores e dispositivos móveis.
- Interface estilo mensageiros (balões de mensagem diferenciados para o remetente, destinatário e sistema).
- Alertas dinâmicos de entrada e saída de usuários na sala.

## 💻 Como executar localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) instalado na máquina.
- Porta `3000` disponível para execução.

### Passo a passo

1. Faça o clone deste repositório ou baixe os arquivos.
2. Abra o terminal na raiz da pasta do projeto.
3. Instale as dependências do pacote executando o comando:
   ```bash
   npm install
4. Inicie o servidor:
   ```bash
   node server.js
5. Abra o navegador e acesse o endereço http://localhost:3000.

- **Dica de teste:** Para testar a troca de mensagens, abra o link acima em duas abas, janelas ou dispositivos diferentes.
